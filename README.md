# Portfolio — Magatte Samaké

My personal portfolio website, built to showcase my Supply Chain background, projects, and professional journey.

I created this website by combining my Supply Chain experience with the web development skills I have been learning along the way.

Rather than using a ready-made template, I wanted to understand how the different pieces of a website work and build my own space to bring my work together.

## What you'll find here

- My Supply Chain & Logistics background
- Professional experience and projects
- Supply Chain case studies
- Data & dashboard projects
- My CV and professional profile


This project is also part of my learning journey in web development and will continue to evolve as I learn and experiment.
